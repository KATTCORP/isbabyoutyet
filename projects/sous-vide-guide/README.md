# Sous Vide Guide

Searchable, translated, linkable sous vide temperatures and cook times. Live
at [sous-vide.katt.dev](https://sous-vide.katt.dev). It is a web-only product,
and everything lives in [`web/`](web/README.md).

Content is adapted from
[KitchenLab's köksguide #9](https://www.kitchenlab.se/koksbloggen/koksguiden-9-sous-vide-temperaturer-och-koktider/)
(attribution only; this is a separate browser for the guide).
